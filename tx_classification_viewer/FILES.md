# File Guide

## Application Files

### `app.R` (Main Application)
The Shiny application. Contains:
- **Fast data loading**: Pre-computed RDS files instead of importing GTFs
- **Memoized difference calculation**: `get_differences()` cached function
- **Lookup tables**: O(1) metadata access instead of filtering
- **UI & Server**: Full Shiny app with difference navigation

**Run locally**: `shiny::runApp()`

### `setup_data.R` (One-Time Setup)
Converts original data files to optimized RDS format.

**Run once**: `Rscript setup_data.R`

Creates all files in the `data/` folder.

### `deploy.R` (Deployment Helper)
Interactive script to deploy to shinyapps.io.

**Usage**: `source("deploy.R")` or `Rscript deploy.R`

Prompts for account, app name, and confirms deployment settings.

## Configuration Files

### `.gitignore`
Controls which files are tracked by git.

**For local development**: Keep `data/*.rds` commented out (don't commit RDS files)

**For shinyapps.io deployment**: Uncomment or remove the `data/*.rds` line so files are included

### `.Rbuildignore` (Optional)
If you package this as an R package, this controls what's excluded from the build.

## Workflow

### Local Development
1. Run `Rscript setup_data.R` (once)
2. Run `shiny::runApp()` to test locally
3. Make changes to `app.R` as needed
4. Test locally

### Deployment to shinyapps.io
1. Read **DEPLOYMENT.md** carefully ⚠️
2. Ensure `.gitignore` doesn't exclude `data/*.rds`
3. Run `source("deploy.R")` or `rsconnect::deployApp()`
4. Wait for deployment (1-2 minutes due to 20MB data)
5. Verify at `https://account.shinyapps.io/app-name/`

### Updating Data
1. Update source files on HPC cluster
2. Run `Rscript setup_data.R` to regenerate RDS files
3. Redeploy to shinyapps.io

## Troubleshooting

**"data/ directory not found"**
- Run `Rscript setup_data.R` to generate files

**Deployment timeout (60 seconds)**
- `data/` folder not deployed (see DEPLOYMENT.md)
- Check `.gitignore` - RDS files must be included

**App loads slowly locally**
- Make sure you're loading from RDS, not importing GTFs
- Check `app.R` line 1-25 for data loading

**Memoization not working**
- Restart R session
- Clear cache: `memoise::forget(get_differences)`
